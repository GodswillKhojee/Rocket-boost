## 🚀 Rocket Boost – 2.5D Spaceship Game

**Rocket Boost** is a physics-based 2.5D spaceship game developed using Unity and C#. Players pilot a spaceship through challenging levels filled with obstacles, using precise rotation and controlled thrust to navigate safely and reach designated landing pads. The game focuses on momentum management, spatial awareness, and precision landings, where a single mistake can lead to a crash.

The game features three handcrafted levels with progressively challenging gameplay. Players can rotate the spaceship using **A** and **D** keys and activate the rocket boost using the **Spacebar**. The project demonstrates physics-based movement, collision detection, player input handling, and level design in Unity.

**Key Features:**
- Physics-based spaceship movement and thrust mechanics.
- Three handcrafted levels with increasing difficulty.
- Obstacle navigation and precision landing challenges.
- Collision detection and crash handling.
- Responsive controls for rotation and boosting.

**Technologies:** Unity, C#, Rigidbody Physics, Collision Detection.
